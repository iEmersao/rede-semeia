Vamos abrir seu espaço de trabalho

Este site precisa iniciar pelo servidor local para carregar as telas e conectar à API.

  1. Na pasta do projeto, abra iniciar-rede-semeia.cmd.
  2. Aguarde alguns segundos. O site abrirá em http://localhost:5173.
  3. Deixe abertas as janelas da API e do site enquanto usa o sistema.

Para carregar cadastros, o MySQL também precisa estar iniciado.
